# IMDb Movie Reviews Sentiment Analysis

## Overview
A Natural Language Processing (NLP) project that analyzes 50,000 IMDb movie reviews to classify sentiments as positive or negative.

## Objectives
- Explore and preprocess movie review text.
- Clean text and apply NLP techniques.
- Train a machine learning sentiment classification model.
- Evaluate model performance using appropriate metrics.

## Dataset
IMDb Dataset of 50K Movie Reviews.

## Technologies
- Python
- Pandas and NumPy
- NLTK
- Scikit-learn
- Matplotlib and Seaborn

## Project Workflow
1. Data loading and exploratory data analysis
2. Text preprocessing
3. Feature extraction using TF-IDF
4. Sentiment classification
5. Model evaluation

## How to Run
1. Install the required libraries: `pip install -r requirements.txt`
2. Open the notebook in Jupyter Notebook or Google Colab.
3. Run the cells in order.
